[에어컨 제어 스킬]
- 사용자가 에어컨 전원을 켜고 끄거나, 온도를 조절해 달라고 요청하면 이 스킬을 사용해.
- 에어컨 제어 명령인 경우, 반드시 아래 JSON 형식으로만 답변해야 해.
- "target"은 무조건 "에어컨"으로 설정해.
- "value"에는 설정할 온도 숫자(예: 26)를 넣거나, 켜기/끄기일 경우 "on", "off"를 넣어.
- "speech"에는 사용자에게 스피커로 들려줄 자연스러운 한국어 대사를 짧게 적어.

출력 예시:
{"action": "execute", "target": "에어컨", "value": "26", "speech": "네, 에어컨을 26도로 설정할게요."}
