# 🍓 라즈베리파이 AI 스마트홈 비서 (Raspberry Pi Edge AI Assistant)

라즈베리파이 5 로컬 환경에서 구동되는 인공지능 기반 스마트홈 제어 에이전트입니다. 마이크를 통한 음성 명령과 디스코드 채팅을 동시에 지원하며, 로컬 LLM을 활용해 사용자의 의도를 파악하고 실제 하드웨어(IoT)를 제어합니다.


## 🚀 주요 기능 (Features)
* **멀티 채널 입력 지원:** 물리 마이크(음성)와 디스코드 봇(텍스트)을 통한 명령을 동시에 비동기로 처리합니다.
* **실시간 음성 인식 (STT) & 합성 (TTS):** `faster-whisper`를 활용해 음성을 텍스트로 변환하고, `edge-tts`로 지연 없는 자연스러운 음성 피드백을 스피커로 출력합니다.
* **동적 스킬 라우팅 (RAG 기반):** 사용자의 명령(예: "에어컨")에 따라 미리 정의된 마크다운 지침서(`Aircon.md` 등)를 읽어와 LLM의 컨텍스트에 주입합니다.
* **LLM 기반 JSON 명령 추출:** Ollama를 통해 구동되는 로컬 LLM이 자연어를 분석하여 하드웨어 제어를 위한 규격화된 JSON 데이터를 생성합니다.
* **실제 하드웨어 연동:** 추출된 JSON 데이터를 바탕으로 `subprocess`를 통해 개별 하드웨어 제어 스크립트(예: `aircon.py`)를 실행합니다.

## 🛠️ 구현 및 아키텍처 (Implementation Details)
* **최적화된 파이프라인:** LLM 호출 횟수를 최소화하기 위해, Python 단에서 1차 키워드 매칭을 수행한 후 필요한 스킬 파일만 LLM 프롬프트에 병합합니다.
* **비동기 스레딩 아키텍처:** 파이썬의 `asyncio`와 `to_thread`를 결합하여 디스코드 이벤트 루프와 마이크 상시 대기(블로킹) 루프가 충돌 없이 완벽히 병렬로 동작합니다.
* **모듈화된 스킬 시스템:** 에이전트의 페르소나(`Agent.md`), 기억(`Memory.md`), 그리고 개별 기기 제어 권한(`Aircon.md`)을 텍스트 파일로 완벽히 분리하여 유지보수와 확장이 용이합니다.
